## 原稿與介面

- `data/vocabulary/guides/nX.json` 是本次新增教材原稿，以既有穩定詞條 ID 對應。`explanation` 記錄繁中解釋；非名詞的 `usageExamples` 另記完整日文、繁中、句中詞形與讀音。全部為專案編寫；原例句的 Tatoeba 署名仍保留。
- `build-word-guides.cjs` 要求每級全部非動詞都有解說；名詞不硬塞同樣模板，其他詞性各有一個與原句不同的完整案例。`import-word-guides.cjs` 可將完整分類的編輯稿匯入。
- 單字卡與已收藏頁共用模板。解釋、原例句、追加案例都在預設收合的區塊內，展開後使用一致的左縮排、邊線與間距；收藏和單字朗讀仍在區塊上方。
- 保留既有分類、詞條 ID、收藏儲存鍵及遷移。原詞表的分類含兼類詞與慣用表達，因此「電波」「センチ」「人柄」等按實際用法說明，沒有因頁面分類強加不自然的な形容詞活用。

## 內容複查

完成全部原稿後，回查詞義、常用搭配、使用對象、完整句意與中文時態、程度、否定及語氣。多音詞、接頭／接尾成分與量詞採句中完整讀音。重要修正包括：

- N5「十／じゅう」改為數字大小比較，避免把「十あります」當一般蘋果計數；「外／ほか」改用假名以免與そと混淆；「温い／ぬるい」同樣使用清楚的假名詞形。
- N4「そんな」案例改成「会って話しましょう」，使見面談話的動作與中文一致。
- N3「角／かく」改用「直角」，與紙角的かど區分；「学」的中文對齊重新設計的工作情境；「暮れ」改用自然的「夕暮れ」。
- 「球」避免先命中「地球」中的同字；「いちご狩り」「田舎育ち」「物干し竿」改標記整個複合詞，使高亮與讀音一致。「三切れ」使用さんきれ。
- N2 接尾「前／ぜん」改用「食前／しょくぜん」，避免把一般讀まえ的「開演前」強讀為ぜん。
- 「殿」的中文不採過度尊崇的「閣下」，而以敬稱說明；部分繁中與委婉表達的措辭亦已調整。

`scripts/review/word-guide-readings.py` 使用獨立 Fugashi / UniDic-lite，掃描全部 2,018 個新增案例。最後列出 90 個讀音候選，均已逐項檢視：包括辛い的からい／つらい、日期讀法、量詞促音與濁音、曜日、御社、東大寺、早急等分析器替代讀音。保留經語境判定的讀音，不將分析器結果直接覆寫為答案。逐項結果與五級原稿雜湊保存在 `data/vocabulary/guides/review.json`，回歸測試會檢查 review 快照是否過期。

## 語音

追加 2,018 個 VOICEVOX 案例音檔，沿用四国めたんノーマル、speaker 2、語速 1.05、停頓比例 0.85。原有 12,288 個例句／文法／答案音檔重用，合計 14,306 個。全部 12,594 個詞彙例句、2,500 個文法例句及答案映射由同一計畫生成。詞彙本身錄音與相づち路由不變。

音檔生成檢查 WAV 時長、音量、削波及 MP3 雜湊；瀏覽器另解碼發布的每個 MP3。程式上的完整性與解碼通過不等同逐句人工試聽，也不證明語調完全等同特定日劇。
