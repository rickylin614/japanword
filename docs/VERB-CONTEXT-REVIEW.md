共改寫 1,914 個例句用途。其餘原型與常用用法經三句對照後保留；不把「全部涵蓋」說成「每一句都重寫」。原創日中例句在 `data/vocabulary/examples/verbs-nX.json`，取代共用前文的舊 `.txt` 模板。每個 ID 獨立保存原型與て形完整句子；必要時以 `common` 覆寫常用句。

主語、受詞、情境與句型分別設計。例如「買う」呈現弟弟買鞋、回程買牛奶與買點心送人；「積む」呈現累積經驗、堆積積木與裝載貨物。て形包括先後、原因、許可、禁止、請求、結果狀態、持續、預先準備及遺憾，不統一接「います」。固定搭配仍保留，沒有強求所有名詞完全不重複。

原有 Tatoeba 常用句保留作者、句 ID、譯文關係及授權。N4「役に立つ」修正助詞搭配，「建てる」改用房屋情境；這兩筆新原創句不沿用舊語料的署名或證據。

## 語言檢查

逐條撰寫時對照詞義與其餘兩句。`scripts/review/verb-contexts.py` 以 Fugashi／UniDic 輔助檢查全部 4,008 個用途的讀音與三句名詞／字串相似度。初次列出 55 組相似候選，修改重複情境後剩 1 組：「化ける」的演員扮老人與故事中的狐狸化人，情境、主語與名詞皆不同，予以保留。這個門檻是編輯提示，不是語意評分或日文正確性的證明。

最終讀音檢查有 68 個候選，涉及分析器對開く、空く、止める、抱く、擦る、解く等同字異音、連濁或複合詞的判讀；逐組對照後保留詞條的明確讀音，語音輸入使用各例句的 `reading`。分析器不能單獨判定讀音正誤。詳細候選報告寫入被 Git 忽略的 `artifacts/verb-context-review/context-review.json`，可重跑工具產生。

特殊修正：

- 得る（うる）：原型使用「起こり得る」，對應可能用法；活用讀「えて」。
- 給う：改為文語「給うて（たもうて）」並保留場合提示，避免一般五段規則產生「給って」。參考[漢字ペディア](https://www.kanjipedia.jp/kotoba/0001406400)的讀音與用法，以及[國立國會圖書館收錄的辭典討論](https://dl.ndl.go.jp/view/prepareDownload?contentNo=1&itemId=info%3Andljp%2Fpid%2F8210366)對促音便形的說明。
- 見慣れる：修正助詞與情境；捲る（めくる）改用裙襬，避免與捲袖子時的「まくる」混淆。
- 要る：保留「要って」較少使用及通常改說「必要で」的提示。
