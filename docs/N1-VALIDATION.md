# N1 複查與第二次提交紀錄（2026-11-03）

使用者要求分成兩階段：先整理目錄、補齊 N1，略過驗證並推送；再檢查翻譯、句型與語氣，修正後第二次推送。第一階段已發布為 `098d338f`，本文件記錄第二階段。這是 Codex 的教材編輯與程式驗證，沒有母語者逐句認證，也沒有宣稱已逐一人工試聽全部錄音。

## 文字與用法

- 複查 2,671 個 N1 詞條的繁中釋義與所選字典義項，以及全部常用例句、402 個動詞的原型／て形情境與 50 個文法單元、500 題。
- 原有 1,358 筆 N1 語料逐筆比對日中句意與目標詞義，留下 159 筆翻譯或例句替換紀錄，見 `data/vocabulary/examples/n1-review-corrections.json`。同一詞可能有不同類型的修正，這不是 159 個互異詞條的計數。保留的語料仍有原文、作者、句子 ID、授權與修改說明。
- 修正「黒字→赤字」、「出動→下班」、「購入…問題にならない→完全沒問題」等意思相反的譯文。「見渡す」句中的玉米田不再譯成小麥田。
- 替換誤配：名詞「とって」不再使用「取って」；「もてる」不再使用「確信は持てない」；「シック」不再使用ホームシック；「ひいては」不再截取「辞書をひいてはいけない」。也修正「お使い」「かぶれる」「いやに」「よし」等誤配。
- 修正 16 個詞條釋義，包括「突く（つつく）」移除別讀音的突襲義、「酪農」改為乳牛畜牧業、「アプローチ」補上處理問題的方法等。
- 文法修正「読んてからというもの」為「読んでからというもの」，「まじき…ではない」的非預期雙重否定，及に足る、そばから、をもって等例句的接續與情境。
- 「ご覧なさい」標示指示語氣及對上位者的限制；「俺」「畜生」「諸君」等補充場合提醒。ものを、たるもの、まじき、べからず、の至り、ところを、でなくてなんだろう的說明區分遺憾、訓誡、批評、禁止、正式感言、請託與反問。

敬意及語氣的參考包括 [國立國語研究所的敬意表現研究](https://repository.ninjal.ac.jp/record/2820/files/kk_nkek_029.pdf)、[文化廳的敬語與場合說明](https://www.bunka.go.jp/seisaku/kokugo_nihongo/kokugo_shisaku/keigo/chapter3/detail.html)；ている的進行／結果狀態參考[國際交流基金說明](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/grammar/201312.html)。詞義與讀音使用專案固定版 JMdict 證據，分級仍來自原有詞表。

## 朗讀與語氣的界線

語料的 `evidence.reading` 是詞條原形讀音，不是句中變化後的讀音。原流程把「明かさ」替換成「あかす」，會造成「あかすなかった」；現在根據活用及句中詞形取讀音。形容詞變化也適用。新增獨立回歸案例，防止再次把原形讀音拼進變化形。

N1 同一句可能教兩個以上的詞，朗讀時會合併各卡片已核對的讀音，例如同時讀對「塵（ちり）」與「塵取り（ちりとり）」。共用同一朗讀輸入會重用音檔。箇条書き等補送假名可在原稿明列句中讀音。

使用 Fugashi／UniDic 對 3,475 組 N1 詞彙例句用法作獨立詞形分析，最後有 76 筆提示，主要是多音字、舊字形、濁音變體或複合詞邊界；逐項與選定讀音核對，並非把分析器的第一候選當成唯一正確讀音。工具位於 `scripts/review/n1-morphology.py`，報告寫入忽略版控的 `artifacts/n1-review/`。

保留四国めたん、話速 1.05、停頓比例 0.85。這是教學用自然會話設定，不是某部日劇的實測速度。合成器會處理問句上揚；文字語用提示不等於每句均已完成演員式情緒或重音人工評聽。VOICEVOX 的調整能力見[官方使用說明](https://voicevox.hiroshiba.jp/how_to_use/)。

全部例句／文法使用 12,194 個 MP3，對應 10,576 組詞彙例句與 2,500 句文法；N1 使用其中 3,341 個互異音檔。單字音檔另有 8,058 個。生成紀錄包含來源雜湊、輸入、讀音、長度、音量與音檔雜湊；已移除不再被映射引用的舊生成音檔。

## 已執行驗證

- `node scripts/run-tests.cjs data`：字典來源、全部詞彙覆蓋、文法、動詞活用、例句可重建性、修正案例、朗讀讀音、映射與音檔雜湊。
- 設定 `PLAYWRIGHT_PATH` 執行各瀏覽器測試：全部 7,904 張卡片、1,336 個動詞的三種例句、預設收合／展開、動作按鈕在例句上方、來源面板、搜尋、收藏、測驗與四種螢幕寬度。
- `test-learning.cjs`：37 頁 × 4 種寬度，25 個詞彙庫 × 2 種測驗模式及舊收藏相容。
- `test-favorites.cjs`：五級與五詞性的交叉篩選、50／51 筆分頁邊界、跨頁籤同步與錄音映射。
- `test-example-audio.cjs`：全部 10,576＋2,500 個播放按鈕對應正確，Chrome 實際解碼全部 12,194 個例句 MP3。
- `test-word-audio.cjs`：全部單字播放路由與 Chrome 解碼 8,058 個單字 MP3。
- `test-conversation.cjs` 與 `verify-aizuchi-prosody.py`：相づち既有 200 個 WAV 的雜湊與 214 個有聲區間音高方向；保留原 A／B 音檔。搬移後的歷史生成器雜湊，改由 `data/speech/renderer-snapshots/` 保存真正生成這些錄音時的程式。

程式驗證證明覆蓋、可載入、播放路由、可解碼與指定讀音／句型回歸案例；它不能單獨證明全部譯文唯一正確或全部合成語氣與真人一致。
