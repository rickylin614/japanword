# 聽力測驗：題庫、分級與校驗

更新日期：2026-11-09。

`public/listening.html?level=n5` 至 `level=n1` 各有 **1,000 題**，共 5,000 題。每級包含 500 題單字辨義、500 題句意理解，均為四選一。題型為聽音辨義練習，不宣稱為官方 JLPT 題型或模擬試卷。

錄音使用既有核對的 VOICEVOX 單字、例句 MP3，共引用 4,948 個不同檔案；不新增瀏覽器機器朗讀後備，也不需要訪客 API 金鑰。這次新增的是測驗及解析，沒有把原有錄音重複複製成 5,000 個檔案。

## 不超級的規則

詞彙級別依本專案固定版本詞表。N5 只用 N5；N4 可含 N5；依此累積至 N1。不是按照例句原先所在的頁面直接推定整句合級。

`scripts/review/grade-listening.py` 使用 Fugashi 1.5.2／UniDic-lite 1.0.8：

1. 分析完整日語原文，逐項對照本級及較低級詞表。
2. 檢查實際書寫形式、還原詞形及漢字相符；不只用讀音把同音異字認成同一詞。例如 N4 不接受經由「点く」誤認的「付く」。
3. 助詞、助動詞、標點與數字常值視為文法／計數基元；其他找不到允許詞條的詞全部拒絕。此門檻驗的是詞彙上限，並非另行認證整句所有文法的官方級別。
4. 每級保留 500 個不重複合格句子，記錄每個片段的來源級別、固定詞條 ID 與原稿雜湊。N4 有 435 個本級來源例句與 65 個 N5 來源例句；其餘級別各取本級來源 500 句。較低級詞彙出現在較高級題目符合累積規則。
5. 以「革命」「主権」、未知字串與同音異字等反例測試門檻，確認較高級或未知內容不能混入低級題庫。

單字題從該級詞表取 500 個詞；排除累積詞表中同音但意思不同的候選，避免只聽單字時無法唯一判斷。錯誤選項排除同中文、過度相似中文及有重疊 JMdict 英文義項的詞，降低多解風險。句意題四項中文不重複，從差異明顯、同樣經分級檢查的例句翻譯取用。

分級不冒充官方逐詞認證；來源本身採固定版 Open Anki／Tanos，JMdict 用於詞形、義項等字典證據。檢查以這份專案可重現的上限為準。

## 作答與解析

- 公布答案前只有播放按鈕、中文問題與選項，不把日語原文或解答放進 DOM。
- 選答後才能公布答案；公布後顯示正誤、正確選項、錄音原文、單字讀音或完整翻譯、重點用法及四選項逐項辨析。
- 句意解析保留原有詞義／用法說明，針對否定、過去形式提供辨識提醒。錯誤選項附其實際對應日語，讓學習者核對差異。
- 原 Tatoeba 例句保留來源 ID、作者、譯文資訊與 CC BY 2.0 FR 署名。
- 支援 10／20／50／全部題目，題型篩選、未作答、錯題重練、離開後續做、本回成績；底部凍結操作列提供上一題、下一題與回到頂部／底部。
- 進度使用獨立 `jp-listening-v1`，不修改原收藏鍵。題目 ID 依來源詞條或原句雜湊穩定產生。未完成回合另保存題庫版本；題庫更新時不把舊選項索引套到新題目上。
- 頁面一次只載入選定等級的約 1.4～1.6 MB 題庫；原文資料雖未顯示，靜態網站的 JS 本身仍可由開發工具查看，不是保密考試系統。

## 檔案與重建

| 路徑 | 用途 |
| --- | --- |
| `data/listening/approved-sentences.json` | 經詞彙門檻檢查的 2,500 句、逐片段證據、固定來源雜湊 |
| `data/listening/audit.json` | 五級題數、生成資料與來源雜湊 |
| `scripts/review/grade-listening.py` | 重新分析原稿與選句；需安裝 Fugashi／UniDic-lite |
| `scripts/build/build-listening.cjs` | 產生每級 1,000 題與解析；`--check` 檢查可重現性 |
| `public/assets/data/nX-listening-data.js` | 瀏覽器使用的單級題庫及版本 |
| `public/assets/js/listening.js` | 聽力介面、判題、續做與音檔播放 |
| `tests/test-listening.cjs` | 全量資料、分級證據與瀏覽器回歸 |

日常 `node scripts/build/build.cjs` 會建置聽力題庫。若詞彙／例句原稿改變，既有來源雜湊會使建置中止；先完成詞彙與例句建置，再執行分級複查及聽力建置：

```sh
python scripts/review/grade-listening.py
node scripts/build/build-listening.cjs
node scripts/build/build-pages.cjs
node tests/test-listening.cjs
```

Python 需要可用的 Node，以及 `fugashi==1.5.2`、`unidic-lite==1.0.8`。沒有這些依賴時，既有已核對選句仍可用 Node 正常重建；不要為通過建置而手改來源雜湊。

瀏覽器測試另設定 `PLAYWRIGHT_PATH`。`scripts/run-tests.cjs` 已納入聽力測驗。
