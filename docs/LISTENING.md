# 聽力測驗：整句錄音與關鍵詞辨音

更新日期：2026-11-14。

`public/listening.html?level=n5` 至 `level=n1` 各有 **1,000 題**，共 5,000 題，全部播放完整例句。已移除單詞錄音題與單字／句意題型選單。

## 作答方式

1. 播放完整日文錄音；畫面提供一句中文句意，其中一個關鍵詞以「【　】」挖空。
2. 四個選項是這個空格的詞義，錯項來自讀音相近的詞，並非四句不相干的翻譯。
3. 選答後才能公布答案。解析顯示日文原句、完整中文、關鍵詞及讀音、拍數，以及每個錯項和正解逐拍的差異、填入錯項後的句意。

例如播放「電車は七時半に出ます」，題目為「【　】七點半發車」，選項比較「電車（でんしゃ）／電話（でんわ）／電燈（でんき）／自行車（じてんしゃ）」。日語原文與選項讀音在答案公布後才顯示。

同一錄音可以考不同位置的詞，題目 ID 由句子、目標詞條及句中位置共同決定。N5 的嚴格合級素材較少，會重用同句考不同詞；不把不同詞的題目宣稱成不同錄音。每句最多 4 個目標，同一詞每級最多出題 32 次。N4～N1 目前各使用 1,000 個不同句子。

## 詞彙上限

等級依專案固定版詞表，N5 僅限 N5，N4 可含 N5，依此累積到 N1。JMdict 用於讀音、詞性及義項，不認證 JLPT 分級。

`scripts/review/grade-listening.py` 以 Fugashi／UniDic-lite 檢查完整日文句子：

- 助詞、助動詞、標點及數字常值為文法／計數基元；其他內容詞都必須對應本級或較低級的固定詞條。
- 比對實際書寫、詞形及漢字，不以同音字代替不同詞。保留「付く／点く」、未知詞及高級詞混入低級的反例測試。
- 頁面標示不直接決定句子等級。N5 也會檢查其他頁面的例句，但只有整句內容詞都通過 N5 門檻才納入候選，未放寬詞彙上限。
- 這是詞彙範圍檢查，不是整句所有文法的官方級別認證。

**正解與全部錯誤選項**也都限於本級及較低級詞表。詞條 ID、來源級別、逐片段證據、原句／譯文及來源雜湊，保存在 `data/listening/approved-sentences.json` 與 `audit.json`。

## 近音選項規則

`scripts/lib/listening-focus.cjs` 按假名的拍序列比較讀音：拗音合為一拍，促音、撥音及長音各保留。以編輯距離排序，清濁音及促音／長音有較小差異權重；優先考慮相近拍數與同詞性，詞義群組只作小幅優先調整。這是近音候選工具，不是量測錄音波形、口音或音高重音的聲學模型。

- 目標使用原文中完整的詞彙形式或其完整假名寫法，不截取動詞活用詞幹來冒充辭書形。
- 排除會混淆字音的同字異讀目標、重複出現而無法唯一定位的目標。
- 錯項與正解讀音不同，四項中文及讀音互不重複；不以未受控制的音高重音作為同音詞唯一解答依據。
- 根據字典實際詞性分類，避免把只有接頭語、接尾語或量詞用途的詞硬放成名詞選項；移除括號中的編輯標籤。
- 排除近義、相同中文及句中已出現的錯項。同類食物、交通、家人、場所等詞有小幅排序優先。
- `focus-policy.json` 保存門檻、中文單字挖空白名單及語意群組。群組中的詞只有同時存在於允許級別詞表時才可作選項。

中文空格以詞表釋義與既有人工編寫／核對的翻譯對齊；保留逐題可重建資料及抽查結果。不宣稱由母語者逐題外部審定。少量選項可被句意排除，學習目標仍包含把近音詞放回整句辨識。

## 錄音與進度

使用已發布的 VOICEVOX 完整例句 MP3，不使用 `audio/words/`，也不新增瀏覽器機器朗讀後備。卡片單字朗讀仍保留，不在這次移除範圍。Tatoeba 句子保留作者、句子 ID 及 CC BY 2.0 FR 署名。

保留 10／20／50／全部、未作答、錯題重練、續做、成績與底部凍結操作列。localStorage 仍使用獨立的 `jp-listening-v1`。新題型使用新的穩定題目 ID 與題庫版本；不把舊單詞題的答案索引套到新題目，舊版本的未完成回合不會顯示續做。收藏鍵不受影響。

## 維護與校驗

- `data/listening/approved-sentences.json`：整句詞彙檢查候選與逐片段證據。
- `data/listening/focus-policy.json`：選詞及近音門檻。
- `scripts/review/grade-listening.py`：重驗詞彙上限；預設收集整句關鍵詞題所需的候選池。
- `scripts/build/build-listening.cjs`：每級產生 1,000 題、解析與版本，`--check` 驗證可重建性。
- `public/assets/js/listening.js`：顯示、判題、播放及進度；`public/assets/data/nX-listening-data.js` 為生成題庫。
- `tests/test-listening.cjs`：5,000 題、空格定位、近音比較、詞性、選項分級、唯一解、來源、音檔映射與瀏覽器互動。

```sh
python scripts/review/grade-listening.py --all-candidates
node scripts/build/build.cjs
node tests/test-listening.cjs
```

分析依賴為 `fugashi==1.5.2`、`unidic-lite==1.0.8`；無依賴時仍可用既有已核對池正常建置。既有例句順序變動而不換句時可用 `--preserve-selection` 重新檢查並重定位索引，不能只更改雜湊。`--legacy-selection` 僅供歷史舊 500 句選集整理，不足以代表新版題庫。

瀏覽器驗證需設定 `PLAYWRIGHT_PATH`。測試會核對五級作答、答案前隱藏原文、填句、讀音解析、錯題、續做、舊版本回合失效、損壞儲存、導覽、四種寬度，以及逐檔解碼題庫實際引用的完整句子音檔。

本次結果：全專案資料測試與聽力瀏覽器測試均通過，5,000 題均無獨立單詞錄音，4,139 個不同整句錄音全部在 Chrome 解碼成功。逐級題數、句子數及五級題目抽查保存在 `data/listening/focus-review.json`；截圖存於忽略的 `artifacts/listening-focus/`。
