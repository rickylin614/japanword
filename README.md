# japanword

N3／N4／N5 日文動詞與情境練習；純 HTML、JavaScript 與 CSV，無需安裝前端套件。

## 啟動與測試

```sh
python -m http.server 8000
```

開啟 http://localhost:8000/n3.html（或 n4.html、n5.html）。三頁都透過 fetch 讀取同目錄 CSV，不能直接以 file:// 開啟。部署時需一併上傳 HTML、quiz.js 與六份 CSV。

```sh
node test.js
```

測試涵蓋所有題型、CSV 格式、答案別名、空白 Enter、輸入法防誤送、混合題型及載入失敗；使用模擬 DOM，不等同真實輸入法測試。

## 操作

- 輸入答案按 Enter 或「提交」檢查；留空（包含全形空白）直接顯示答案與解析，不計答對。
- 答錯保留原題，可看解析後再試。
- 答對保留解析，再按 Enter／提交或「下一題」繼續；與舊版立即跳題不同，方便閱讀解析。
- 「下一題」隨時可跳過；切換題型清除舊提示。同一題型有多題時不連續抽到同一道題。
- 日文輸入法組字中的 Enter 及長按 Enter 不送出。發音使用瀏覽器語音功能，實際可用聲音依裝置而定。

## 已實作題型

| 題型 | 說明 |
| --- | --- |
| 中文 → 原形 | 接受原形與題庫中的假名讀音 |
| 原形 → ます／て／ない／た形 | 從動詞 CSV 出題；括號內的假名標註可作答案別名 |
| 漢字 → 假名讀音 | 僅抽取原形含漢字的詞，答案使用發音欄 |
| 變形 → 原形 | 從ます／て／ない／た形反推原形，題目標示來源形式 |
| 混合題型 | 先隨機選題型，再抽題，包含進階題，避免大量動詞淹沒進階題 |
| N5 助詞填空 | 12 題，地點、受詞、時間、所有、工具、起訖、列舉等 |
| N4 情境對話 | 12 題，許可、禁止、進行、經驗、建議、順序、義務等 |
| N3 近義詞／自他動詞辨析 | 各 8 題，共 16 題，提供選詞範圍及解析 |

進階題為本專案原創教材，分級為練習安排，不宣稱為官方 JLPT 題目或經官方分級認證。

## 題庫維護

三頁共用 `quiz.js`，依 body 的 `data-level` 讀取：

- `n3.csv`／`n4.csv`／`n5.csv`：動詞、變化、中文、發音。
- `n3_questions.csv`／`n4_questions.csv`／`n5_questions.csv`：進階題與解析。

動詞依「標題名稱」而非欄位位置解析，支援 N5 與 N3／N4 不同欄序；支援 BOM、CRLF、引號、欄位內逗號與換行。必要欄位不全或資料損壞時顯示錯誤並停用作答。

N4 部分 `た形` 欄原本空白，載入時從既有て形末尾 `て→た／で→だ` 補齊；有填た形的資料優先使用原值。其他既有詞形未全面重新校訂。

### 新增進階題

標題列固定為：

```csv
id,type,prompt,answers,explanation
n5-new01,9,机の上（　）本があります。請填入表示存在位置的助詞。,に,存在的位置用 に。
```

- `id`：檔案內唯一識別碼。
- `type`：9 為該級進階題；N3 的 10 為自他動詞題。
- `prompt`：含語境、空格及作答限制。需避免多解；若多解合理，全部列入答案。
- `answers`：用 `|` 分隔可接受答案，例如 `に|へ` 或 `食べる|たべる`。依 NFKC 正規化並去除前後空白後精確比對，不做自由文字語意評分。
- `explanation`：繁體中文解析，作答或查看答案後才顯示。
- 欄位含逗號或換行時以雙引號包住；欄位內雙引號寫成兩個雙引號。

舊的 `generate_n3.py` 已停用覆蓋 HTML 的功能，避免把頁面還原成內嵌題庫。直接維護 HTML 與 CSV 即可；`n3_annotated.csv` 不作為目前頁面的載入來源。
