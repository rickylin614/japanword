# japanword

N3／N4／N5 日文動詞與情境練習；純 HTML、JavaScript 與 CSV，無需安裝前端套件。

## 啟動與測試

```sh
python -m http.server 8000
```

開啟 http://localhost:8000/n3.html（或 n4.html、n5.html）。三頁都透過 fetch 讀取同目錄 CSV，不能直接以 file:// 開啟。部署時需一併上傳 HTML、quiz.js 與六份 CSV。

```sh
node test.js
```

測試涵蓋所有題型、CSV 格式、答案別名、空白 Enter、輸入法防誤送、混合題型及載入失敗；使用模擬 DOM，不等同真實輸入法測試。

## 操作

- 輸入答案按 Enter 或「提交」檢查；留空（包含全形空白）直接顯示答案與解析，不計答對。
- 答錯保留原題，可看解析後再試。
- 答對保留解析，再按 Enter／提交或「下一題」繼續；與舊版立即跳題不同，方便閱讀解析。
- 「下一題」隨時可跳過；切換題型清除舊提示。同一題型有多題時不連續抽到同一道題。
- 日文輸入法組字中的 Enter 及長按 Enter 不送出。發音使用瀏覽器語音功能，實際可用聲音依裝置而定。

## 已實作題型

| 題型 | 說明 |
| --- | --- |
| 中文 → 原形 | 接受原形與題庫中的假名讀音 |
| 原形 → ます／て／ない／た形 | 從動詞 CSV 出題；括號內的假名標註可作答案別名 |
| 漢字 → 假名讀音 | 僅抽取原形含漢字的詞，答案使用發音欄 |
| 變形 → 原形 | 從ます／て／ない／た形反推原形，題目標示來源形式 |
| 混合題型 | 先隨機選題型，再抽題，包含進階題，避免大量動詞淹沒進階題 |
| N5 助詞填空 | 12 題，地點、受詞、時間、所有、工具、起訖、列舉等 |
| N4 情境對話 | 12 題，許可、禁止、進行、經驗、建議、順序、義務等 |
| N3 近義詞／自他動詞辨析 | 各 8 題，共 16 題，提供選詞範圍及解析 |

進階題為本專案原創教材，分級為練習安排，不宣稱為官方 JLPT 題目或經官方分級認證。

## 題庫維護

三頁共用 `quiz.js`，依 body 的 `data-level` 讀取：

- `n3.csv`／`n4.csv`／`n5.csv`：動詞、變化、中文、發音。
- `n3_questions.csv`／`n4_questions.csv`／`n5_questions.csv`：進階題與解析。

動詞依「標題名稱」而非欄位位置解析，支援 N5 與 N3／N4 不同欄序；支援 BOM、CRLF、引號、欄位內逗號與換行。必要欄位不全或資料損壞時顯示錯誤並停用作答。

N4 部分 `た形` 欄原本空白，載入時從既有て形末尾 `て→た／で→だ` 補齊；有填た形的資料優先使用原值。其他既有詞形未全面重新校訂。

### 新增進階題

標題列固定為：

```csv
id,type,prompt,answers,explanation
n5-new01,9,机の上（　）本があります。請填入表示存在位置的助詞。,に,存在的位置用 に。
```

- `id`：檔案內唯一識別碼。
- `type`：9 為該級進階題；N3 的 10 為自他動詞題。
- `prompt`：含語境、空格及作答限制。需避免多解；若多解合理，全部列入答案。
- `answers`：用 `|` 分隔可接受答案，例如 `に|へ` 或 `食べる|たべる`。依 NFKC 正規化並去除前後空白後精確比對，不做自由文字語意評分。
- `explanation`：繁體中文解析，作答或查看答案後才顯示。
- 欄位含逗號或換行時以雙引號包住；欄位內雙引號寫成兩個雙引號。

舊的 `generate_n3.py` 已停用覆蓋 HTML 的功能，避免把頁面還原成內嵌題庫。直接維護 HTML 與 CSV 即可；`n3_annotated.csv` 不作為目前頁面的載入來源。

## 完整學習入口（2026-10）

建議使用 `node serve.cjs`，開啟 http://127.0.0.1:8000/layout.html 。原有 `python -m http.server 8000` 也可使用。

- `layout.html`／`index.html`：共同學習總覽，可切換所有新舊頁面。
- `n3-nouns.html`、`n3-adjectives.html`、`n3-others.html`：N3 名詞 150 詞、形容詞 100 詞、其餘詞性 100 詞。
- `n4-nouns.html`、`n4-adjectives.html`、`n4-others.html`：N4 名詞 150 詞、形容詞 100 詞、其餘詞性 100 詞。
- `grammar.html?level=n3`（也可選 n4、n5）：每級 105 題，合計 315 題。每級 21 種句型，各 5 個獨立情境，附四選一答案與繁體中文解析。這些是新文法題庫，不以原本動詞變化或舊進階題湊數。
- 原有 `n3.html`、`n4.html`、`n5.html` 與 CSV、quiz.js 保留，補上跨頁導覽及手機樣式。

詞彙支援搜尋、收藏、假名輸入（包含片假名正規化）、中文選擇與朗讀；收藏依詞彙 ID 保存。詞彙小測每輪使用目前篩選結果，離開頁面會結束該輪。

文法可選 10 題、20 題或全部，並篩選未練習／錯題。每題只計分一次；看答案列入待複習。文法進度按等級保存，重新整理可按「繼續上次」。開始新輪會取代該等級未完成的輪次，但不清除累積紀錄。統計以最近一次答案為準；答對後該題移出錯題池。

所有新頁面共用 learning.css、learning.js，資料分別在 vocabulary-data.js、grammar-data.js；原版導覽補充在 legacy-navigation.js。build-pages.cjs 可重新產生新 HTML，並對舊頁補上一次導覽 script，不改題庫。

進度與收藏使用 localStorage（jp-learning-v1），主題沿用 theme。資料只保存在同一瀏覽器與同一網址來源，不會跨裝置同步；無法存取儲存空間時會顯示提示。新增頁面使用 script 載入題庫，可直接開啟 HTML，但原版動詞 fetch CSV 仍需 HTTP，建議所有頁面都從上述伺服器使用。

### 手機測試

PowerShell 執行 `$env:HOST='0.0.0.0'` 後再執行 `node serve.cjs`，手機與電腦連接同一 Wi-Fi，以 `http://電腦的區域網路IP:8000/layout.html` 開啟（需防火牆允許該連接埠）。預設只監聽本機 127.0.0.1。

### 新增驗證

`node test-learning.cjs` 驗證每級題數、唯一 ID／情境、四個不同選項、唯一答案與六份詞彙資料；`node test.js` 繼續驗證既有動詞功能。

若本機已安裝 Playwright，可將 PLAYWRIGHT_PATH 設為其模組路徑，再執行 `node test-learning.cjs`。預設使用已安裝的 Edge，BROWSER_CHANNEL 可改為 chrome。瀏覽器測試涵蓋 12 頁在 360、390、768、1440px 的橫向溢位檢查，以及導覽、主題、搜尋、收藏、兩種詞彙測驗、三個文法等級的計分、續答、錯題重練、未練題目與儲存不可用情境。螢幕截圖會輸出在測試目錄。這是桌面瀏覽器模擬視窗測試，不等於實體 iOS／Android 測試；朗讀取決於裝置是否有日文語音。


### 詞彙擴充與全題發音（2026-10-02）

六個分類合計 700 個條目（每級 350）。N4 加入生活、飲食、居家、交通與基礎複習；N3 加入社會、經濟、工作、時間、情緒與進階表達。跨級保留少量複習及易混淆詞，不宣稱為 700 個跨級不重複單字，亦非官方完整 JLPT 單字清單。每筆包含日文、假名、繁體中文與詞性；同級同分類不以漢字／假名異寫灌水。舊詞彙的 ID 不變，既有收藏可沿用。

- 單字列表、假名輸入題、中文選擇題：作答前可按「聽單字發音」，作答後也可朗讀答案。
- 文法題：題幹朗讀將空格念為「空欄」，不揭露答案；每個日文選項有獨立發音按鈕，播放不會提交答案或計分。答題後及錯題清單可朗讀完整句子。
- 原版動詞題：保留題目發音，補上顯示答案後的「聽答案發音」。
- 使用裝置的 speechSynthesis 日文語音，優先選取 ja 語音。重複點擊會取消上一段再播放。播放失敗顯示提示；需裝置具備日文語音。

新增瀏覽器測試以模擬語音 API 驗證各題型的按鈕實際送出日文朗讀、按播放不作答、作答後仍可播放；不代表已人工聆聽各裝置音色。詞彙總量及各分類數量由資料動態計算。
